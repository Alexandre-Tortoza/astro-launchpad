# Examples

These directories are generated by the `create-astro-launchpad` CLI. They are
reference projects for the three content strategies and are **not** workspace
members.

| Directory | CMS | Notes |
|---|---|---|
| `landing-markdown` | Markdown files | Static build, no Docker required |
| `landing-directus` | Directus 12 | `docker compose up -d` starts the CMS |
| `landing-strapi` | Strapi 5 | `docker compose up -d` starts the CMS |

## Recreating the examples

```bash
# From the repo root — build the CLI first
pnpm --filter create-astro-launchpad build
node scripts/build-examples.mjs
```

## Running an example

1. Copy the env template and fill in any secrets:
   ```bash
   cp .env.example .env
   ```
2. Follow the preset's README or `prompts/` folder for next steps.
