# SEO

Treat SEO metadata and page copy as accurate editorial content, not keyword containers.

- Supply a concise, unique `seo.title` and factual `seo.description` when page context supports them.
- Keep heading structure meaningful in the rendered block sequence.
- Use specific link text that describes the destination or action.
- Write alt text for informative images; decorative images can use an empty alternative only when the component supports that intent.
- Do not claim rankings, traffic, search volume, or indexing behavior without supplied evidence.
- Flag canonical URLs, structured data, and crawl behavior as implementation concerns when they are outside the current content schema.
