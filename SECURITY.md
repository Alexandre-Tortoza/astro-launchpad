# Security Policy

## Supported versions

Only the latest published `0.0.x` release receives security fixes.

## Reporting a vulnerability

Do not open a public issue. Use the repository's GitHub private vulnerability reporting feature and include reproduction steps, affected versions, and potential impact. Maintainers will acknowledge reports within seven days and coordinate disclosure after a fix is available.

## Supply-chain controls

Dependencies are updated by Renovate only after they have been published for at least three days. Every update remains subject to CI and human review before merge.
